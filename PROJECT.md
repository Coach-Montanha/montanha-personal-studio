# Project: Montanha Personal Studio Mobile Wrapper

## Architecture
- **Wrapper Engine**: Capacitor 8.5.2 (`@capacitor/core`, `@capacitor/android`, `@capacitor/cli`).
- **WebView Strategy**: Hosted production SSR application at `https://montanha-personal-studio.vercel.app` with `androidScheme: 'https'`.
- **Static Resiliency**: Fallback shell in `public/index.html` copied to `.output/public` to ensure offline loading screen and valid `webDir` for Capacitor CLI.
- **Native Android Platform**: `android/` directory containing Gradle project, locked to `portrait` orientation, hardware acceleration enabled, adjustResize soft input mode, and minimal permissions (`INTERNET`, `ACCESS_NETWORK_STATE`).
- **Asset Pipeline**: Zero-npm asset scaling using Windows built-in .NET System.Drawing generating all Android mipmap densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) from `public/icon-512.png`.
- **Build Automation**: Defensive local build script (`scripts/build-apk.ps1`) protecting host 14GB disk space + cloud-based GitHub Actions CI pipeline (`.github/workflows/build-apk.yml`) building debug/release APKs on Ubuntu runners with zero local disk footprint.
- **Mobile Compliance**: CSS safe-area insets (`pt-safe`, `pb-safe`) for status bars/notches, input auto-zoom prevention (>= 16px), coarse-pointer 44x44px minimum touch targets, native Capacitor service worker guard, and multi-tenant security enforcement.

## Code Layout
- `capacitor.config.ts`: Capacitor project configuration (appId, appName, webDir, server URL, webview flags).
- `public/index.html`: Offline/initial loading fallback shell.
- `android/`: Native Android project generated by Capacitor CLI.
  - `android/app/src/main/AndroidManifest.xml`: Permissions, orientation, theme, network security.
  - `android/app/src/main/res/xml/network_security_config.xml`: Network security domain configuration.
  - `android/app/src/main/res/values/strings.xml`, `colors.xml`: App branding strings and colors.
  - `android/app/src/main/res/mipmap-*/ic_launcher*.png`: Generated mipmap launcher icons.
  - `android/app/src/main/res/drawable/splash.png`: Splash screen drawable.
- `scripts/sync-android-assets.ps1`: Zero-dependency PowerShell script to generate Android mipmap icons from public PNGs.
- `scripts/build-apk.ps1`: Guarded local APK build script with disk space and toolchain pre-flight checks.
- `.github/workflows/build-apk.yml`: Zero-bloat GitHub Actions workflow for automated APK building and artifact publishing.
- `src/styles.css`: Safe-area CSS custom properties and coarse-pointer touch target expansion.
- `src/components/edufinance/AppShell.tsx`: Header safe-area top padding and main safe-area bottom padding.
- `src/components/portal/PortalShell.tsx`: Header safe-area top padding.
- `src/routes/__root.tsx`: Native Capacitor guard for PWA service worker registration.
- `tests/e2e-mobile/`: Opaque-box E2E test suite verifying mobile wrapper requirements, config syntax, android XML, and CI workflow.

## Interface Contracts
### Web App ↔ Capacitor Bridge
- `capacitor.config.ts`: Must export default `CapacitorConfig` with `appId: "com.ecossistemamontanha.personalstudio"`, `appName: "Montanha Personal Studio"`, `webDir: ".output/public"`.
- Server URL: Defaults to `"https://montanha-personal-studio.vercel.app"`, overridable by `process.env.CAPACITOR_SERVER_URL`.

### Android Native ↔ Web Bundle
- Asset directory: `android/app/src/main/assets/public/` populated by `npx cap sync android`.
- Fallback page: `public/index.html` compiled to `.output/public/index.html` before sync.
- Network Security: `android/app/src/main/res/xml/network_security_config.xml` linked in `AndroidManifest.xml`.

### Build Pipeline ↔ Artifact Output
- Local script: `scripts/build-apk.ps1` accepts optional `-BuildType` (Debug/Release, default Debug) and `-Clean` flag. Exits 0 on success, outputs path to `.apk`.
- CI Workflow: `.github/workflows/build-apk.yml` runs on `ubuntu-latest`, outputs artifact named `montanha-personal-studio-debug-apk`.
